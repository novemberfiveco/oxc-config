# @novemberfiveco/oxc-config

Shared [oxc](https://oxc.rs) (oxlint + oxfmt) configuration and setup tooling for November Five projects — the oxc equivalent of `@novemberfiveco/eslint-config`.

| Package                                              | Description                                     |
| ---------------------------------------------------- | ----------------------------------------------- |
| [`@novemberfiveco/oxc-config-vite`](./packages/vite) | oxlint + oxfmt config for Vite / React projects |
| [`@novemberfiveco/oxc-config-cli`](./packages/cli)   | `init` CLI that scaffolds oxc setup into a repo |

See [docs/migration.md](./docs/migration.md) for the full adoption guide.
